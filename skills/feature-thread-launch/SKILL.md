# Feature Thread Launch

此技能服务显式的新任务请求。仅仅任务复杂、有长日志或需要 worktree，不构成创建用户可见任务的理由。

- 先查看当前可用任务工具和项目列表；核实项目、Git 状态及用户指定起点。
- 准备简短启动包：目标、约束、相关文件、已有进展、接口、验收方式和隔离需求。
- 尊重用户模型选择；未指定时继承工具规定的默认值，不在新任务中擅自降档。
- 按工具支持选择 local/worktree；用户指定分支时使用实际分支，不编造起点。不要求为隔离而再造用户任务。
- 调用工具后使用返回的真实 ID；异步创建须等待可用状态。完成摘要由真实任务输出取得，不伪造回报。
- 新任务内部存在独立工作时主动用子代理并行，声明文件归属，自己继续关键路径。
- 工具不可用时先完成交接材料并如实说明；不要将普通开发停在“请新建任务”。

只有用户要求合并、归档、外部动作时，才按该动作授权和当前工具边界执行。

需要交接格式时读 `references/feature-thread-launch-checklist.md`。
