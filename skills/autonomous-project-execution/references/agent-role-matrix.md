# 按需角色选择

按工作选择职责；此表不是固定团队或执行顺序。角色定义职责与行为约束，模型在编排时选择。表中“只读”不代表独立沙箱，权限继承与能力配置见 [适配说明](../../../docs/client-compatibility.md#子代理权限与生命周期)。

| 角色 | 独立职责 | 执行边界 |
| --- | --- | --- |
| worker | 负责一个文件组的实现、修复和相关验证 | 限定写入范围 |
| explorer-lite | 有具体问题的只读代码定位 | 只读 |
| reviewer-lite | 正确性与回归首轮复核 | 只读 |
| security-reviewer | 授权边界、敏感数据、高风险代码深度复核 | 只读 |
| tester-lite | 失败日志归因与最近验证路径 | 只读 |
| planner | 依赖关系或阶段确实不清时补短计划 | 只读 |
| summarizer-lite | 压缩已经提供的大量证据 | 只读 |
| refiner | 指定范围的文档或机械整理 | 限定写入范围 |
| pr-preparer | 根据实际差异起草交付说明 | 只读 |
| security-lite | 范围明确的初筛，不能替代深度复核 | 只读 |
| orchestrator | 复杂项目中按需协助统筹，根 Codex 主任务仍负责系统级决策与验收 | 明确统筹范围 |

## 动态模型选择

- 主任务保持用户选定模型；内置子代理默认从当前可用模型中选择相对根主任务低一个能力档且胜任的模型。能力依据工具说明与任务需求，不按型号数字、价格或推理强度排序；沿用已核实信息。外部 Agent 的选型按 [执行模式](autonomous-execution-workflow.md#划分工作) 判断能力与总成本，不套用内置模型的档位关系。
- 工作包传递根主任务的模型基准与总预算，嵌套委派不逐层降档。高复杂实现、关键架构或高风险复核可选同档；能力不足时由主任务接管或按写入交接规则改派，不反复低档重试。
- 模型按工作包选，推理强度按调查深度选。契约明确的实现优先用所选模型的默认强度；跨系统归因或需区分多种解释时可提高强度，不按交付篇幅判断。角色文件不固定型号或强度；通过宿主支持的创建参数表达选择，不把请求值当作已生效值。
- 无法确认根模型或能力顺序、没有合适执行者或接口不支持选型时，不传覆盖参数，遵循执行环境的配置解析，或由主任务执行。不猜型号、不为选型反复联网，不修改机器配置；未确认实际选择时不声称继承、降档或降低成本。

自定义角色与内置角色同名时会覆盖后者。模型/推理设置的解析顺序见 [客户端适配说明](../../../docs/client-compatibility.md#模型路由)。
