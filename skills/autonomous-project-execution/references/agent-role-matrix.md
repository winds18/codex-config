# 按需角色选择

按工作选择职责；此表不是固定团队或执行顺序。角色只定义职责与权限，模型在编排时选择。

| 角色 | 独立职责 | 执行边界 |
| --- | --- | --- |
| worker | 负责一个文件组的实现、修复和相关验证 | 限定写入范围 |
| explorer-lite | 有具体问题的只读代码定位 | 只读 |
| reviewer-lite | 正确性与回归首轮复核 | 只读 |
| security-reviewer | 授权边界、敏感数据、高风险代码深度复核 | 只读 |
| tester-lite | 失败日志归因与最近验证路径 | 只读 |
| planner | 依赖关系或阶段确实不清时补短计划 | 只读 |
| summarizer-lite | 压缩已经提供的大量证据 | 只读 |
| refiner | 指定范围的文档或机械整理 | 限定写入范围 |
| pr-preparer | 根据实际差异起草交付说明 | 只读 |
| security-lite | 范围明确的初筛，不能替代深度复核 | 只读 |
| orchestrator | 用户要求分层大项目时协助统筹，不剥夺主任务实现职责 | 明确统筹范围 |

## 动态模型选择

- 主任务保持用户选定模型；委派默认从当前工具支持且可用的模型中，选择相对根主任务低一个能力档、足以完成工作包的模型。以工具能力说明和任务需求判断，不按型号数字、价格或推理强度排序；沿用本任务已核实的模型信息。
- 工作包传递根主任务的模型基准，嵌套委派不逐层降档。高复杂实现、关键架构或高风险复核可选同档；能力不足时由主任务接管或按原写入交接规则改派，不反复低档重试。
- 本仓库角色不固定 `model` 或 `model_reasoning_effort`。支持时由编排者在创建调用中显式传入所选模型；推理强度按工作难度与该模型支持范围选择，默认沿用所选模型的默认值，不照搬父任务高档设置。
- 无法确认根模型或能力顺序、没有可用次档或接口不支持选型时，不传覆盖参数，遵循宿主配置解析，或由主任务执行。不猜型号、不为选型反复联网，不修改机器配置；未确认实际选择时不声称继承或降档。

自定义 worker 会覆盖宿主内置同名角色。角色文件中的模型/推理设置会覆盖创建参数；旧会话仍锁定角色配置时，可用允许显式选型的角色传入等效职责与权限约束，不能削弱隔离；否则遵循宿主配置或本地执行。删除固定值不会让客户端自动计算“次一级”，动态选择依赖编排指令与实际工具。配置优先级与可用性见 [适配说明](../../../docs/client-compatibility.md)。
