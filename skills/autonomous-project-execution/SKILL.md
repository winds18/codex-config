# Autonomous Project Execution

先明确目标与完成标准，复用已有架构和契约，补齐指导当前实现所需的边界后并行打通真实主路径。普通细节沿用项目惯例合理假设并推进，不逐阶段报批或要求固定名称的 spec/plan。

- Codex 自主开发与外部 Agent 协作可按任务组合，不以项目大小划硬界；执行投入较大且委派有收益时，优先利用已授权外部能力。主任务保留目标、架构、共享契约、关键取舍及集成验收责任，解决关键不确定性并推进未委派关键路径，不重复实现或只转发消息；详细分流见并行执行与交接。
- 工作包给出目标、写入归属、接口、已有授权及限制、验收；跨环境工作明确各执行位置和可达入口，分配资源时补复用入口、额度与回收责任。共享范围只有一个活跃负责人；改派先确认停止写入并交接差异，授权不能随委派扩大。
- 验证当前集成结果及必要失败路径；有效检查通过后，仅因相关变化、具体失败或明确覆盖缺口补验。非阻塞建议留到交付时简记；自有临时资源用完即回收并核实，保留项明确交接。
