# 项目 AGENTS.md 最小模板

复制下面正文时替换占位项，删除不适用段落。只记录真实命令、项目例外和不能从代码直接看出的约定；不要复制全局工作流。

```markdown
# 项目工作约定

## 目标与边界

- 交付目标：<具体结果>。
- 必须保持：<兼容性、数据或产品约束>。
- 本次排除：<明确不做的内容>。
- 规模与性能约束：<实际输入规模/并发量、既定指标及适用条件；未定义则删除>。

## 入口与命令

- 关键目录：<入口与模块职责>。
- 安装/启动：<真实命令>。
- 停止/清理：<针对任务自有资源的真实命令及作用范围；无此需求则删除>。
- 目标测试：<真实命令>。
- 集成验收：<真实命令或可观察结果>。
- 其他必须检查：<项目已有要求；没有则删除>。
- 性能测量：<实际基准命令、代表数据/场景及基线入口；无需求则删除>。

## 协作约定

- 架构/接口事实源：<现有模块边界、类型或 schema 路径>。
- 共享接口/锁文件负责人：<角色或规则>。
- 运行资源归属：<任务自有资源的归属确认规则及隔离方式；不得回收的既有共享服务/缓存/持久数据；无此需求则删除>。
- 临时文件与证据：<任务临时目录及清理方式；需保留的日志/产物路径、用途及保留方式>。
- 保留服务：<稳定的保留条件、停止入口及交接记录位置；不保留则删除>。
- worktree 准备：<实际命令；没有则删除>。
- 已有设计/架构事实源：<真实路径；没有则删除>。

## 风险与交付

- 额外授权边界：<本项目的真实限制>。
- 提交、分支和发布：<遵循既有约定>。
```

跨阶段项目可加一份短计划，参考 [project-plan-template.md](project-plan-template.md)。不将动态任务列表长期放进 AGENTS；普通修复不要求补齐计划或 changelog。

资源生命周期详细规则统一见 [软件工程流程](../skills/autonomous-project-execution/references/software-engineering-workflow.md)；模板只补项目真实命令与例外，不复制通用清单。动态实例身份、状态及负责人写入实际交接记录，不固化在 AGENTS。
