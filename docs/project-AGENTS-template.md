# 项目 AGENTS.md 最小模板

复制下面正文时替换占位项，删除不适用段落。只记录真实命令、项目例外和不能从代码直接看出的约定；不要复制全局工作流。

```markdown
# 项目工作约定

## 目标与边界

- 交付目标：<具体结果>。
- 必须保持：<兼容性、数据或产品约束>。
- 本次排除：<明确不做的内容>。

## 入口与命令

- 关键目录：<入口与模块职责>。
- 安装/启动：<真实命令>。
- 目标测试：<真实命令>。
- 集成验收：<真实命令或可观察结果>。
- 其他必须检查：<项目已有要求；没有则删除>。

## 协作约定

- 架构/接口事实源：<现有模块边界、类型或 schema 路径>。
- 共享接口/锁文件负责人：<角色或规则>。
- 并行运行资源：<数据库/端口/输出目录如何隔离；无冲突则删除>。
- 临时文件与证据：<任务临时目录及清理方式；需保留的产物路径>。
- worktree 准备：<实际命令；没有则删除>。
- 已有设计/架构事实源：<真实路径；没有则删除>。

## 风险与交付

- 额外授权边界：<本项目的真实限制>。
- 提交、分支和发布：<遵循既有约定>。
```

跨阶段项目可加一份短计划，参考 [project-plan-template.md](project-plan-template.md)。不将动态任务列表长期放进 AGENTS；普通修复不要求补齐计划或 changelog。
