## 独立技能试用

独立代理按当前技能及工程参考，在独占临时目录实现按账户汇总流水的纯函数：一次性迭代输入、整数最小货币单位、允许退款、拒绝 bool、首个坏记录报告 1 起始行号，输出按账户排序且不修改输入。

方案为单遍字典累计后排序账户，期望时间 O(n + k log k)、额外空间 O(k)，其中 n 为行数、k 为账户数。12 项测试通过，覆盖只读/一次性输入、边界与失败路径，以及 60 组独立随机对照。

以下为该代理回报的本机测量：Python 3.9.6、macOS arm64；耗时计入生成器输入构造，每组 7 次取中位数，Python 分配峰值另以 tracemalloc 测量。

| 行数 / 账户数 | 耗时中位数 | Python 分配峰值 |
| --- | ---: | ---: |
| 100,000 / 10,000 | 48.777 ms | 1.603 MiB |
| 200,000 / 20,000 | 99.227 ms | 3.171 MiB |
| 200,000 / 1 | 89.532 ms | 0.001 MiB |
