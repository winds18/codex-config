| 层 | 原问题 | 当前行为 | 预期收益 |

| 技能 | 工作流默认全量读取、前端双 token 真源 | 精确触发，参考按需读，沿用已有实现/设计事实源 | 降低规则冲突与维护成本 |

| 安全检查 | merge/跨远程漏扫、命令字符串误判 | 扫描目标历史，覆盖 merge；区分直接执行和文本资料 | 修复已复现漏检与误报 |

并行流程已贯穿 AGENTS → 治理文档 → 项目模板 → workflow skills → 角色 → 前端共享接口规则。没有把“要求并行”仅写在总纲里。主任务与子代理各自有真实工作；容量不足或任务本身串行时继续执行，不把派出代理当成完成条件。

## 已剔除或降为按需项的旧规则

删除默认新建功能任务、主任务只做控制面、全局禁止并行写不同模块、固定角色接力、固定文档五件套、每步 goal delta/线程台账、压缩后全量重读、每次重复验证四件套，以及 Stop/SubagentStop 的关键词/长度门禁。

删除 hook 全局注入的架构/前端/工作习惯清单、模型代际硬禁、代理可自行设置的破坏性命令放行环境变量。普通 Git 风险操作的 hook 输出改为有限提示，真实授权仍由请求和客户端权限决定。

前端删除强制复制 token YAML、每次都生成完整 DESIGN.md/Motion Contract、固定五段输出及 ease-in、fade、时长等绝对美学禁令。保留已有设计一致性、键盘与触控、reduced motion、状态正确性和实际渲染验证。

保留 11 个角色和旧脚本名称以兼容现有入口；其职责及默认行为已更新。不是按文件年龄删除，而是按是否有实际作用、是否重复和是否与当前能力冲突处理。

## 交叉复核追加修复

安装实现完成后，独立复核再次找到四个具体问题，均在临时目录复现后修复：

1. **真源覆盖（P1）**：目标与仓库重叠会生成自身循环链接并移除源内容。现在安装前拒绝相交路径，覆盖配置根与技能目录两种情况。
2. **Git 路径失真（P2）**：strip/splitlines 丢失合法空白。现在 NUL 分隔保留前后空格、换行及多值配置。
3. **损坏 manifest 阻断恢复（P2）**：有效 journal 存在却先读损坏 manifest。现在 recover 先读事务，元数据恢复使用临时文件和原子替换。
4. **Git hooks 骤停丢失原配置（P2）**：更新 hooksPath 后、写 manifest 前退出会丢失 before。现在首次改 Git 配置前保存 pending journal，提供 `--recover`；两种真实子进程骤停回归覆盖 unset 后和 hooksPath 写入后。

## 部署前仍需知道的限制

- 本次只修改克隆仓库。真实已安装配置是否更新、hook 是否受信任、当前客户端是否发现技能，没有由临时测试推定。安装入口默认预览，使用见 [README](../../README.md)。
